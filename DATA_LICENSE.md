# Data licence

The files under `data/` are derived from ball-by-ball data published by
**[Cricsheet](https://cricsheet.org)** and are shared under the
**[Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)](https://creativecommons.org/licenses/by-sa/4.0/)** licence,
the same terms Cricsheet publishes its data under (check <https://cricsheet.org> for their current terms).

If you use or redistribute this data you must:

1. **Attribute** Cricsheet (<https://cricsheet.org>) and this project.
2. **Share alike**: release any derivative of the data under CC BY-SA 4.0.
3. Indicate whether you changed it. This project reshapes ball-by-ball records into per-match and per-player
   summaries and adds computed columns (e.g. `points`).

The source code (`src/`, `tests/`, scripts, workflows) is MIT licensed; see `LICENSE`.
Data in `data/provisional/` comes from contributor-supplied sources and is temporary: it is deleted once
Cricsheet publishes the match.
